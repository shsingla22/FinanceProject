# QualityRisks — end-to-end verification (124 companies)

The skill was verified on a stratified 124-company set: hand-picked archetypes for every risk channel (steel/oil cyclicals, capital-goods makers, defence and utility PSUs, retailers facing quick commerce, tobacco/liquor, paints, IT/internet), the universe's most quant-flagged companies, all 15 financially-stressed names, and clean compounders as negative controls.

**Verification results:**

- 124/124 analysed; 112 with the full Opus concall judge, 12 honestly quant-only (no transcripts on file — e.g. ITC, Trent, Abbott India).
- All 741 quotes across the judged verdicts traced to the raw transcripts (97% matched automatically; the rest located manually — all were PDF text-extraction artifacts, none fabricated).
- Archetype expectations met: Tata Steel/ONGC → Cyclicality HIGH; Coal India/NTPC/IRCTC/HAL → Government Dependency HIGH; Motherson → Concentration; Asian Paints/Page → Good Enough; Berger/DMart → New Entrants; Naukri/TCS → Technological Innovation; Nestlé/Pidilite (controls) → no HIGH risks.
- Manual report review fixed four honesty/wording issues (no-transcript companies claiming 'no signal'; improving returns described as 'held'; an 11-point return moderation described as 'no slide'; wide margin ranges called 'steady'). All are now locked in by tests (17 passing).
