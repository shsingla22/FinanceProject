# Companies and Years Satisfying Each Balance-Sheet Pattern

**Universe:** Nifty 500 (all 500 constituents)
**Period:** FY 2015 → FY 2026
**Methodology:** for each pattern, lists every (company, base year T)
observation that matched the BS criteria evaluated using data through
year T, along with the *realized* forward stock-price CAGR over the
subsequent N years (where N = pattern's horizon).

**'Met target'**: Y = the company's actual forward CAGR met or exceeded
the CAGR threshold of the pattern (success); N = it fell short (failure).
