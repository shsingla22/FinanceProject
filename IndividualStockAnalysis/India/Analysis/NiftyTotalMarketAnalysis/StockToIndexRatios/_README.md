# Stock vs Nifty 50 — price and earnings ratio reports

Generated by `Skills/StockToIndexPriceEarningsRatio` for the ten
top-rated companies of the quality ranking. Each report divides the
company by the Nifty 50 on three measures (share price, net profit,
operating profit), one point per fiscal year, up to the last 15 years.

Regenerate any report from the skill's `scripts/` folder:

    python3 analyze.py report SYMBOL out.md

Note: METROPOLIS and CORONA from the ranking's top tier have no stored
share-price file, so the next-ranked companies (THELEELA, GILLETTE)
stand in; COLPAL's stored profit-and-loss ends at FY2010, so its report
carries a full price chart plus an explicit coverage note instead of
guessed earnings ratios.
